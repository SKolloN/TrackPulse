# TrackPulse — Now Playing for OBS

Локальное расширение + сервер: текущий трек из **Яндекс Музыки**, **VK**, **Spotify** или **YouTube Music** показывается в OBS.

Репозиторий: [github.com/SKolloN/TrackPulse](https://github.com/SKolloN/TrackPulse)

## Самый быстрый старт

1. Скачайте релиз: [Releases](https://github.com/SKolloN/TrackPulse/releases/latest)
2. Распакуйте в постоянную папку (например `C:\Tools\TrackPulse`)
3. Запустите **`INSTALL.bat`**
4. В Edge: режим разработчика → **Загрузить распакованное** → путь из буфера
5. Включите музыку
6. В OBS → Browser Source:
   - URL: `http://127.0.0.1:18181/`
   - Width `800`, Height `150`, FPS `30`
   - не включайте «Завершать работу источника, когда он не виден»

Дальше обычно достаточно **`START.bat`** (трей) и **`UPDATE.bat`** при обновлениях.

## Основные bat в корне

| Файл | Зачем |
|---|---|
| `INSTALL.bat` | Первая установка |
| `UPDATE.bat` | Обновление с GitHub |
| `START.bat` | Трей + сервер |
| `STOP.bat` | Остановить сервер |

Дополнительное (диагностика, автозапуск, тест трека и т.п.) лежит в **`scripts\`**.

## Админка

История → замок, пароль по умолчанию: `admin` (смените).

Там: тест OBS, стили, виды (классика / компакт / расширенный), приоритет источника, служебная инфа.

## История

Фильтр источника, топы 7/30 дней, экспорт CSV / Markdown / HTML, хронология по 40 на страницу.

## Данные

| Файл | Что это |

| `data\stream-history.json` | Эфиры |
| `data\api-token.txt` | Локальный API-токен |
| `data\overlay-theme.json` | Тема |

| `logs\server.log` | Лог |

## Безопасность

- только `127.0.0.1`
- треки не уходят в интернет (кроме проверки релизов GitHub)
- мутации API — по локальному токену
