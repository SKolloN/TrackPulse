# TrackPulse — Now Playing for OBS

Локальное расширение + сервер: текущий трек из **Яндекс Музыки** или **VK** показывается в OBS.

Репозиторий: [github.com/SKolloN/TrackPulse](https://github.com/SKolloN/TrackPulse)

## Самый быстрый старт (рекомендуется)

1. Скачайте свежий релиз: [Releases](https://github.com/SKolloN/TrackPulse/releases/latest)
2. Распакуйте ZIP в постоянную папку (например `C:\Tools\TrackPulse`)
3. Запустите **`INSTALL.bat`**
4. В открывшемся Edge:
   - включите **Режим разработчика**
   - **Загрузить распакованное**
   - вставьте путь из буфера (Ctrl+V) и выберите папку
5. Включите музыку в Яндекс Музыке или VK
6. В OBS добавьте **Browser Source**:
   - URL: `http://127.0.0.1:18181/`
   - Width: `800`
   - Height: `150`
   - FPS: `30`
   - не включайте «Завершать работу источника, когда он не виден»

Готово. Сервер уже запущен в режиме постоянной записи.

> Edge/Chrome не дают полностью «тихо» ставить распакованные расширения без режима разработчика — это ограничение браузера. `INSTALL.bat` делает всё остальное за вас.

## Обновление одной кнопкой

1. Запустите **`UPDATE.bat`** в папке расширения  
   (или в popup расширения нажмите **«Проверить обновление»** → затем `UPDATE.bat`)
2. Откройте `edge://extensions`
3. Нажмите **Reload / Обновить** у TrackPulse  

Удалять расширение не нужно. Папка `data\` (история, токен, тема) сохраняется.

В popup также есть кнопка **GitHub / релизы**.

## Что делают bat-файлы

| Файл | Назначение |
|---|---|
| `INSTALL.bat` / `SETUP.bat` | Быстрая установка: сервер + путь в буфер + страница расширений Edge |
| `UPDATE.bat` | Скачать последний релиз с GitHub и обновить файлы на месте |
| `start-daemon.bat` | Фоновый сервер, эфир всегда активен, журнал пишется постоянно |
| `start-overlay.bat` | Запуск сервера и открытие оверлея в браузере |
| `start-server-only.bat` | То же, что daemon, без лишних сообщений |
| `stop-overlay.bat` | Остановить локальный сервер |
| `test-overlay.bat` | Отправить тестовый трек и открыть оверлей |
| `diagnose-server.bat` | Запуск сервера в консоли для диагностики |
| `install-autostart.bat` | Автозапуск сервера при входе в Windows |
| `remove-autostart.bat` | Убрать автозапуск |

## Настройка OBS

1. Sources → Add → **Browser**
2. URL: `http://127.0.0.1:18181/` (кнопка в popup копирует адрес)
3. Width `800`, Height `150`, FPS `30`
4. После обновления файлов: свойства источника → **Refresh cache of current page**

## Админка

На странице истории нажмите **🔒**, пароль по умолчанию: `admin`.

Там:
- тест оверлея
- стили/пресеты без правки кода
- токены и пути файлов
- приоритет источника VK/Яндекс
- смена пароля

## Где хранятся данные

| Файл | Что это |
|---|---|
| `data\listening-journal.json` | Постоянный журнал треков |
| `data\stream-history.json` | История эфиров |
| `data\api-token.txt` | Локальный API-токен |
| `data\overlay-theme.json` | Тема оверлея |
| `data\settings.json` | Настройки приоритета источника |
| `logs\server.log` | Лог сервера |

## Безопасность

- сервер только на `127.0.0.1`
- данные не уходят в интернет (кроме проверки обновлений GitHub по кнопке/таймеру)
- мутирующие API защищены локальным токеном
