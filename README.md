# TrackPulse — Now Playing для OBS

Локальное расширение для Edge/Chrome + маленький сервер на вашем ПК.  
Показывает **текущий трек** в OBS из вкладок:

- Яндекс Музыка  
- VK  
- Spotify  
- YouTube Music  

Данные треков **не уходят в интернет** — только на `127.0.0.1`.  
Проверка обновлений ходит на GitHub (по кнопке / таймеру в popup).

Репозиторий: [github.com/SKolloN/TrackPulse](https://github.com/SKolloN/TrackPulse)

## Быстрый старт

1. Скачайте последний релиз: [Releases](https://github.com/SKolloN/TrackPulse/releases/latest)
2. Распакуйте в постоянную папку (например `C:\Tools\TrackPulse`) — потом её лучше не переносить
3. Запустите **`INSTALL.bat`**
4. В Edge:
   - включите **режим разработчика**
   - **Загрузить распакованное**
   - вставьте путь из буфера и выберите папку
5. Включите музыку в поддерживаемом сервисе
6. В OBS → Sources → Browser:
   - URL: `http://127.0.0.1:18181/`
   - Width: `800`, Height: `150`, FPS: `30`
   - не включайте «Завершать работу источника, когда он не виден»

Дальше в повседневке: **`START.bat`** (трей) и **`UPDATE.bat`** при выходе новой версии.

## Файлы в корне

| Файл | Назначение |
|---|---|
| `INSTALL.bat` | Первая установка: сервер + путь в буфер + страница расширений |
| `UPDATE.bat` | Скачать свежий релиз с GitHub и обновить файлы (папка `data\` сохраняется) |
| `START.bat` | Иконка в трее + локальный сервер |
| `STOP.bat` | Остановить сервер |

Дополнительное (диагностика, автозапуск Windows, тест трека, daemon без трея) — в папке **`scripts\`**.

## Что внутри продукта

- **Оверлей для OBS** — карточка now playing с прогрессом, марquee, видами:
  - классика (пластинка + обложка)
  - компактный
  - расширенный (анимация влёта пластинки)
- **История** — постоянный журнал и сессии эфира, фильтры, топы, экспорт CSV / Markdown / HTML
- **Админка** (замок на странице истории, пароль по умолчанию `admin`) — тест в OBS, тема, приоритет источника, служебные пути/токен
- **Несколько вкладок** — выбирается играющий источник; можно задать приоритет

## Данные на диске

| Файл | Содержимое |
|---|---|
| `data\listening-journal.json` | Постоянный журнал прослушивания |
| `data\stream-history.json` | История эфиров |
| `data\api-token.txt` | Локальный ключ API (только этот ПК) |
| `data\overlay-theme.json` | Тема и настройки вида оверлея |
| `data\settings.json` | Приоритет источника и таймауты |
| `logs\server.log` | Лог сервера |

## Безопасность

- Сервер слушает только `127.0.0.1`
- Мутирующие запросы защищены локальным API-токеном
- Это **неофициальное** расширение; товарные знаки сервисов принадлежат их владельцам
