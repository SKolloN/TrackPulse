  • Автор не гарантирует совместимость с будущими обновлениями браузеров, сайтов музыки, OBS и ОС.
  • Автор не гарантирует точность отображаемых метаданных трека.
  • Любые обновления, поддержка и ответы на вопросы — исключительно по желанию автора.

5. Конфиденциальность и данные

  • Расширение читает метаданные текущего трека только на доменах из манифеста.
  • Данные по умолчанию остаются на вашем ПК: локальный сервер 127.0.0.1 и локальные JSON-файлы.
  • Автор не получает вашу историю треков, пароли, cookies и содержимое других сайтов через это расширение.
  • Проверка обновлений может обращаться к GitHub API/странице релизов — только для версии, без отправки вашей музыкальной истории.
  • Вы сами контролируете, что показываете на стриме через OBS.
