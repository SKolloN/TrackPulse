Локальное расширение · без облака

Политика конфиденциальности TrackPulse

TrackPulse работает только на вашем компьютере. Расширение не регистрирует аккаунты, не собирает аналитику и не отправляет данные на внешние серверы.

Что читается

  • Метаданные текущего трека на вкладках поддерживаемых музыкальных сайтов: название, исполнитель, альбом, обложка, позиция воспроизведения.
  • Только на явно указанных доменах из манифеста.

Куда уходят данные

  • Только на локальный сервер http://127.0.0.1:18181.
  • История сохраняется в локальных JSON-файлах рядом с сервером.
  • Никакие запросы во внешний интернет расширение само не делает.

Чего расширение не делает

  • Не читает другие сайты.
  • Не перехватывает пароли, сообщения и платежи.
  • Не загружает удалённый код.
  • Не использует микрофон, камеру, буфер обмена и захват вкладки.

Безопасность

Мутирующие API локального сервера защищены токеном. Публичное состояние оверлея не содержит URL страницы и служебных ошибок. Сервер слушает только loopback-интерфейс.
